# ASMR 播放器

一个基于 Tauri + Vanilla JS 构建的轻量级本地音频/视频字幕播放器。

## ✨ 功能特性
- 支持本地音频和视频播放
- 支持导入 SRT、LRC 等多种格式的字幕并实时同步
- 支持自定义背景图片
- 独立的桌面应用，轻量且防熄屏

## 📦 下载安装
请前往 [Releases](https://github.com/moss514/audio-player/releases) 页面下载最新的安装包 (`.exe`)。

## 🛠️ 开发构建
```bash
# 安装依赖
npm install

# 开发模式运行
npm run tauri dev

# 打包构建
npm run tauri build
