# ASMR 播放器

一个轻量级、纯净无广告的本地音视频字幕播放器。基于 Tauri + Vanilla JS 构建，主打本地播放、字幕同步与沉浸式体验。

## 📥 下载与安装
请前往 [Releases](https://github.com/moss514/audio-player/releases) 页面，下载最新版本的 `ASMR_x.x.x_x64-setup.exe` 安装包。
*(注：软件体积极小，仅约 1.3MB，双击一路“下一步”即可安装)*

---

## ✨ 现有功能
- [x] **本地媒体播放**：支持导入本地音频（MP3, WAV, M4A 等）与视频（MP4, WebM 等）。
- [x] **多格式字幕支持**：支持导入 SRT、LRC、VTT 等常见字幕格式，并实时同步滚动。
- [x] **沉浸式背景**：支持自定义导入背景图片，打造个性化播放环境。
- [x] **防熄屏功能**：调用系统 Wake Lock，听长音频时自动保持屏幕常亮。
- [x] **独立桌面应用**：纯本地运行，无需打开浏览器，不依赖网络。

---

## 📖 操作指南
1. 安装并打开软件。
2. 点击左上角的 **☰ 菜单** 按钮展开侧边栏。
3. 点击 **🎵 导入音频及字幕**（或 🎬 导入视频及字幕），在文件选择器中按住 `Ctrl` 多选音频文件和对应的字幕文件。
   *(注意：请将音频和字幕按顺序排好，播放列表会按文件名自动匹配)*
4. 点击 **🖼️ 导入背景图片** 可以更换背景。
5. 点击播放条上的播放按钮即可开始享受。

## 🚧 待改不足（To-Do List）
*   **UI 过于简陋**：侧边栏和播放器控件使用的是浏览器原生样式，后续可考虑用 Tailwind CSS 美化。
*   **拖拽导入未实现**：目前必须通过菜单选择文件，希望能支持直接把音视频/字幕拖拽到窗口内。
*   **字幕样式固定**：目前字幕大小和颜色是写死的，后续可增加一个设置面板调整字体大小和透明度。
*   **缺少记忆播放**：关闭软件后再次打开，无法记住上次播放到的位置。
*   **快捷键支持**：缺少全局快捷键（如空格键播放/暂停、方向键快进快退）。
